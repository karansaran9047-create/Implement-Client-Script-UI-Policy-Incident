# Implement Client Script & UI Policy (Incident)

## Project Overview
This ServiceNow micro project demonstrates how UI Policies and Client Scripts can enforce data integrity on Incident records.

## Repository Structure

8. Project Demonstration

## Main Features
- High Impact UI Policy
- Assignment Group mandatory control
- Urgency read-only control for High Impact
- Automatic Urgency update using an onChange Client Script
- Save validation using an onSubmit Client Script
- List-edit blocking using an onCellEdit Client Script
- Testing for mandatory enforcement, successful save, reverse condition, list edit blocking, and form-based update
